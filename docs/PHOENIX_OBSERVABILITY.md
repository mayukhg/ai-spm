# Arize Phoenix — Application Tracing (Option 1)

For the product/PM view of the eval framework (hosting, parameters, persona rationale), see [`PHOENIX_EVAL_FRAMEWORK.md`](./PHOENIX_EVAL_FRAMEWORK.md).

## What was integrated

| Piece | Location |
| --- | --- |
| Tracer bootstrap | `server/observability/tracer.ts` |
| App entry import | `server/index.ts` (loads tracer before LLM clients) |
| Instrumentable LLM client | `server/governance/openrouter-client.ts` (OpenAI SDK → OpenRouter) |
| Chain wrapper | `server/governance/async-compliance.ts` (`withSpan` around report synthesis) |
| Eval fixtures | `fixtures/synthetic/phoenix/` |
| Seed script | `npm run phoenix:seed` |

## Architecture

```
Async governance report
  → CHAIN span (governance.synthesize_report)
    → OpenAI SDK chat.completions (OpenInference auto-instrumented)
      → OpenRouter (openai/gpt-4o-mini)
        → OTLP/HTTP → Phoenix collector (:6006)
```

Realtime Practical Fast Math paths are **not** instrumented as LLM calls (by design).

## Local Phoenix

```bash
# Example: run Phoenix UI locally (Docker)
docker run -p 6006:6006 -i arizephoenix/phoenix:latest

# Seed synthetic eval traces + local scoring artifact
npm run phoenix:seed
```

Open `http://localhost:6006` → project `my-cursor-app` (or `PHOENIX_PROJECT_NAME`).

## Environment

See `.env.example`. Append to your existing `.env` (do not overwrite other secrets):

```env
# Arize Phoenix Configurations
PHOENIX_COLLECTOR_ENDPOINT="http://localhost:6006"
PHOENIX_PROJECT_NAME="my-cursor-app"
PHOENIX_CLIENT_HEADERS="" # Format: api_key=your_key (Leave blank for local)
```

## Synthetic eval data

| File | Purpose |
| --- | --- |
| `fixtures/synthetic/phoenix/eval-dataset.json` | 5 governance eval cases + evaluator rubrics |

Without `OPENROUTER_API_KEY`, the seed script still emits OpenInference LLM spans using synthetic outputs so Phoenix is populated for demos.
